# EquiVoice Script Writer

## Purpose

Garantir que tous les scripts audio MyEquiVoice respectent strictement la **Charte Éditoriale Audio v1** (`charte editoriale audio _ v1.md`). Ce skill agit comme un exécuteur de règles éditoriales pour la génération et la révision de scripts.

## When to Use

- Quand l'utilisateur demande d'écrire un nouveau script audio.
- Quand l'utilisateur demande de réviser ou corriger un script existant.
- Quand l'utilisateur mentionne "Charte Éditoriale", "Charte Audio" ou "Editorial Charter".
- Quand on écrit du contenu pour des séances MyEquiVoice (Échauffement, Exercice, Récupération).

## Instructions

1.  **Charger la Charte Éditoriale** :
    -   Lire `references/editorial-guidelines.md` (contient la Charte Éditoriale Audio v1 complète). C'est la SOURCE DE VÉRITÉ.
    -   Source originale : `05_PRODUCTION_CONTENUS/LES_REGLES/charte editoriale audio _ v1.md`

2.  **Appliquer les Règles de Structure (Partie 1)** :
    -   **Rituels de marque** : Débuter par "Bonjour et bienvenue dans ta séance MyEquiVoice." / Terminer par "Merci pour ta confiance et à très bientôt sur MyEquiVoice."
    -   **Modulation visuelle** : Mode BRIEFING (paragraphes groupés, pause à la fin) vs Mode GUIDAGE (1 ligne = 1 action).
    -   **Balises obligatoires** : `## [NOM DE LA SECTION] (XX:XX - XX:XX)`
    -   **Pauses explicites** : `[Pause : XX secondes]` avec calibrage réaliste.
    -   **Silences habités** : Dressage = max 25-30s de silence, Obstacle = Tunnel de Silence 45-60s.

3.  **Appliquer la Pédagogie (Partie 2)** :
    -   **Vocabulaire par niveau** : G3-G4 = mécanique (aides précises) / G5-G7 = sensation (ressenti).
    -   **Architecture de l'effort** : Briefing d'Anticipation → Split Troubleshooting → Signal d'Action → Silence Complice → Feedback.
    -   **Schéma tactique** : Préparation AVANT l'action (dans le tournant), jamais pendant.

4.  **Appliquer le Bien-être et Rythme (Partie 3)** :
    -   **Échauffement au pas** : 5 min (courte) / 7-8 min (moyenne) / 10 min (longue). Jamais moins de 5 min.
    -   **Pauses récupération** : 60-120s entre chaque bloc d'effort intense.
    -   **Diversité** : Échauffements variés et originaux, adaptés au thème.
    -   **Galop Plaisir** : G3 = pas de galop récréatif / G4+ = 3-5 min de galop plaisir en fin de séance technique.

5.  **Appliquer la Précision Géographique (Partie 4)** :
    -   **Dressage** : Lettres de manège obligatoires.
    -   **Obstacle** : Lettres pour orientation initiale, puis repères d'obstacles.
    -   **Moment de réflexion** : Question de coaching au pas rênes longues, JAMAIS pendant l'effort.

6.  **Appliquer le Style Oral (Partie 5)** :
    -   **Effet "Moniteur en Live"** : Contractions naturelles, interjections, pas de vocabulaire scolaire.
    -   **Feedbacks variés** : Max 2 utilisations du même mot par séance.
    -   **Conclusion chaleureuse** : Valoriser le couple cavalier/cheval.

7.  **Appliquer les Règles Spécifiques (Partie 6)** :
    -   **Symétrie obligatoire** : Temps, contenu et structure identiques à chaque main.
    -   **Répétition par niveau** : G3-G4 = répéter les consignes à la 2ème main / G4-G5+ = autonomie.
    -   **Diagonal** : G3-G4 = explication complète au 1er trot / G5+ = rien.
    -   **Pied** : G3 = explication complète au 1er galop / G5+ = rien.
    -   **Type de trot** : TOUJOURS préciser "trot assis" ou "trot enlevé".

8.  **Appliquer les Règles Obstacle (Partie 7)** :
    -   **Installation via popup** : Le script commence en selle, obstacles déjà en place.
    -   **Logistique solo** : Max 2-3 dispositifs, 4-6 obstacles, zéro descente de cheval.
    -   **Tunnel de Silence** : 45-60s dès le signal d'action, silence total pendant le saut.
    -   **Répétitions** : Max 5 passages par dispositif.

9.  **Appliquer la Sécurité Juridique (Partie 8)** :
    -   **Rituel de mise en route** : Vérification sangle/casque/environnement intégrée naturellement.
    -   **Cavalier Pilote** : Jamais d'ordres absolus → conditionnel et clauses de décision.
    -   **Invisibilité juridique** : Sécurité déguisée en conseil technique de performance.

10. **Règles de Sortie** :
    -   **Langue** : TOUJOURS en FRANÇAIS.
    -   **Format** : Lignes courtes (max 60 caractères) pour faciliter la lecture rythmique.
